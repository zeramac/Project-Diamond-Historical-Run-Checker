Runs entirely in your browser — files are parsed locally and never uploaded anywhere. Matching is exact on the trimmed, case-insensitive combination of Advertiser, Product and Brand within the selected system ("Outdoor" and "OOH" are treated as the same system). Switching the system above clears the files loaded so far, since the historical runs and the new-run format both depend on which system is selected. For Digital, Radio, OOH and Print, the new-run file is filtered down to just the rows tagged with the selected system before matching; TV skips that filter and matches directly against a dedicated TV new-run file, since TV's format has no Category/System columns to filter on.
